第１回のまとめ

HTMLとは

Webページの「骨組み」を作る言語です。HTML（HyperText Markup Language）は、文章に「ここは見出し」「ここは画像」と意味づけ（マークアップ）をして、ブラウザに構造を伝えます。見た目の装飾はCSS、動きはJavaScriptが担当します。

gitとは

Gitは、ファイルの変更履歴を管理し、過去の状態に戻したり、複数人で安全に作業できるようにするバージョン管理ツールです。コードの“セーブポイント”を作る仕組みだと考えると分かりやすいです。

タグの書き方

タグは < > で囲んで書きます。開始タグと終了タグで内容を挟むのが基本で、全体を「要素」と呼びます。

タグ意味ポイント
<h1>〜<h6>見出しh1が最大。1ページに1つが基本。見た目で選ばず階層で選ぶ
<p>段落前後に自動で余白がつく
<br>改行段落を分けたいときは <p> を使う
<hr>区切り線話題の切れ目に
<strong> / <em>重要 / 強調太字・斜体になるが、本来は「意味」を表す
<span>文中の一部をまとめるCSSで装飾するときに便利（意味はなし）

gitへのpush方法

初回のみ：ユーザー情報を設定する

git config --global user.name  "あなたの名前"
git config --global user.email "you@example.com"
1

リポジトリを用意する

GitHubで「New repository」を作成します。すでにあるものは git clone URL で取得します。

git init                        # 新規フォルダをGit管理にする
git branch -M main              # ブランチ名をmainに
git remote add origin https://github.com/ユーザー名/リポジトリ名.git
2

状態を確認する

git status
3

変更をステージに載せる（add）

git add index.html   # 1ファイルだけ
git add .            # すべての変更
4

履歴として記録する（commit）

メッセージには「何をしたか」を短く書きます。

git commit -m "トップページのHTMLを作成"
5

GitHubへ送る（push）

初回は -u を付けて送り先を覚えさせると、次回から git push だけでOKです。

git push -u origin main   # 初回
git push                  # 2回目以降
