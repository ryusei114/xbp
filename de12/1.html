HTMLとは


Webページの「骨組み」を作る言語 HTML（HyperText Markup Language）は、文章に「ここは見出し」「ここは画像」と意味づけ（マークアップ）をして、ブラウザに構造を伝える言語です。見た目の装飾はCSS、動きはJavaScriptが担当します。

タグの書き方

タグは< >で囲んで書きます。開始タグと終了タグで内容を挟むのが基本で、全体を「要素」と呼びます。
< h1 >〜< h6 > 見出し h1が最大。1ページに1つが基本。見た目で選ばず階層で選ぶ
< p > 段落 前後に自動で余白がつく
< br > 改行 段落を分けたいときは< p >を使う
< hr > 区切り線 話題の切れ目に
< strong > / < em > 重要 / 強調 太字・斜体になるが、本来は「意味」を表す
< span > 文中の一部をまとめる CSSで装飾するときに便利（意味はなし）

gitへのpush方法


初回のみ、ユーザー情報を設定します。
初回だけコピー
git config --global user.name "あなたの名前"
git config --global user.email "you@example.com"
１.リポジトリを用意する
GitHubで「New repository」を作成。すでにあるものは git clone URL で取得します。
git init # 新規フォルダをGit管理にする
git branch -M main # ブランチ名をmainに
git remote add origin https://github.com/ユーザー名/リポジトリ名.git
２.状態を確認する
git status
３.変更をステージに載せる（add）
git add index.html # 1ファイルだけ
git add . # すべての変更
４.履歴として記録する（commit）
メッセージには「何をしたか」を短く書きます。
git commit -m "トップページのHTMLを作成"
５.GitHubへ送る（push）
初回は -u を付けて送り先を覚えさせると、次回から git push だけでOKです。
git push -u origin main # 初回
git push # 2回目以降
